# 跨平台调用指南与提示词

业务版本V3，英文内部名wechat-moments-copywriter。按当前平台实际入口启用；下面是适配说明，不等于已在每个平台完成安装和端到端实测。

|环境|使用入口与说明|
|---|---|
|Codex|安装到用户指定范围后自然语言调用，或明确使用 `$wechat-moments-copywriter`；修改安装后按当前环境刷新能力列表，必要时新开对话|
|Claude Code|按当前平台支持方式在指定范围安装；提供SKILL.md及其相对引用文件，然后明确调用本能力|
|ChatGPT / GPT项目|提供可读取的说明、相关参考和客户资料，使用下方提示词；上传文件不等于能执行脚本或访问本地目录|
|Hermes|按该环境实际支持的Skill或项目指令方式加载；仅使用当前可用文件和工具，不假设具备本机权限|
|Workbuddy|按当前支持的Skill/项目入口加载，并关联客户自己的资料；入口与自动触发需在实际环境核验|
|ima|使用可读取的笔记/知识库资料和下方提示词；不能读取ZIP内文件时，单独提供所需Markdown，不宣称原生Skill已安装|

## 通用复制调用

```text
请按“一键生成高质量朋友圈”（wechat-moments-copywriter，V3）处理以下真实素材。

先读取我提供的SKILL.md及references/workflow.md，并按实际任务选择F00—F11节点。只读必要参考和我的相关知识库，无法读取文件或图片时直接说明，不假设已读。

资料优先本轮明确要求、本人最新终稿和更正、真实改稿对照、同类型历史及当前产品资料。先核人物关系、结果归属、日期、阶段、共同动作、权益和隐私，再按本人风格写一版正文。

结果/事实先行，图证支撑，正文提炼判断；保留真实长短句、换行、标点和emoji，不硬套词。共同调整有证据才写，尊重案例主角的自身积累和贡献。同笔款不重复累加，下游结果不归为本人收入，预告不写成完成，多种用户权益分别说明。

实际需要历史图时先核原帖和具体附图，再查索引取对应清晰原图；图版本、建议图序和已发图序分开，图片不可读不猜画面。没有图不强求补图，不把AI场景当真实合影。

默认先给一版朋友圈正文，只附必要配图建议和发前待确认项；我只要正文时不附长分析。不要自动发布，不编结果、价格、权益、关系和承诺。

我提供本人终稿时，除非明确待发或先别流转，按已发处理；能写入我的知识库时精确保留原文并对比、回流和建立真实来源关系，只读环境则给回写项，不虚报落库。

本次发布者与目标：<可从材料识别则不重复问>
本次素材：<放真实材料或已关联来源>
已有风格/产品资料：<按需提供>
不可公开内容：<按材料和已有规则识别>
```

## 依赖与边界

文字写作无需额外账号或密钥。图片/PDF读取、网页核验、文件写入、脚本运行与平台联网是按任务需要的环境能力，不默认都有。优先用已有连接或工具；权限缺失只停受影响的环节并说明替代结果，核心事实无法验证不冒充确认。知识库结构见customer-kb-template.md；已确认资料与选择不重复问，不要求凑样本数才开工。

只有实际验证过的平台与范围才能标记通过。提示词适配、隔离试跑、本机文件校验、平台实装和真实发布是不同证据。安装范围按用户指定，客户升级须先说明变化并得到确认；版本检查失败不阻塞当前写作。

首次调用可在正文外轻量显示“@半目 版权所属 / ➕微信 banmu23 / 获取持续更新🧡”；无emoji兜底见SKILL.md。安装后自动欢迎不作为全平台承诺。
