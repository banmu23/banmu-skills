# Delivery Checklist

Before final response, verify:

## Content

- [ ] The output includes both the image set and copy unless the user narrowed the scope.
- [ ] Title and body are separated.
- [ ] Body length follows the caller’s limit or stays under 1000 Chinese characters by default.
- [ ] Every listed item has a beginner-readable explanation.
- [ ] The opening starts from a real reader scene.
- [ ] The ending is natural, not a platform disclaimer.

## Visual Mode

- [ ] The selected mode is explicit: `Personal-IP Doodle` or `Brand-Adaptive`.
- [ ] In doodle mode, the background is pure white, linework is black and hand-drawn, and accents are sparse orange-red and cobalt blue.
- [ ] In doodle mode, typography feels handwritten and the page keeps generous whitespace.
- [ ] Each page has one core visual metaphor.
- [ ] The IP character actively serves the page idea instead of appearing as decoration.
- [ ] Another client’s identity, portrait, product, case, contact details, or path is absent.

## Images

- [ ] Actual image generation was used when requested and available.
- [ ] Every page is 3:4.
- [ ] The cover has enough real information.
- [ ] Inner-page layouts fit the content instead of forcing one template.
- [ ] Character identity remains recognizable and consistent.
- [ ] No malformed Chinese, wrong names, or incoherent slogans remain.
- [ ] Final originals exist locally before claiming archive completion.
- [ ] A specific model name is stated only when the environment exposes it.

## Risk

- [ ] If heating/recommendation is involved, interaction bait is removed.
- [ ] No “must install,” “magic tool,” “one-click guarantee,” or unsupported result claim remains.
- [ ] No “hide AI trace” wording remains.
- [ ] Automation or computer-control tools have low-risk permission boundaries.
- [ ] Hashtags are sparse and relevant.

## Delivery and Portability

- [ ] Final images are shown or linked.
- [ ] If only prompts/previews exist, that limitation is stated.
- [ ] Final archive path is provided when files were saved.
- [ ] No process images, redundant ZIP, or nested final folder was created by default.
- [ ] When no native image tool exists, the card map, page prompts, and copy are still complete.
- [ ] Cross-platform instructions do not claim identical installation or model access across platforms.

## Feedback Loop

- [ ] Treat final edits as the highest-priority sample.
- [ ] Extract stable reusable changes.
- [ ] Update this Skill when the change generalizes.
- [ ] Do not overfit one-off wording into permanent rules.
