# Client Variables

This Skill must work for the owner, teammates, and clients. Treat the following as variables.

| Variable | What to ask or infer |
|---|---|
| Account owner | Who is speaking, role, tone, and public identity |
| Target reader | Newbie, operator, founder, teacher, consultant, creator, or another audience |
| Platform mode | WeChat image post, Xiaohongshu image note, both, or heating/recommendation |
| Topic | Tool list, workflow, tutorial, case, product, method, or checklist |
| Materials | Draft, screenshots, product facts, tool facts, review notice, or final sample |
| Visual mode | `Personal-IP Doodle` or `Brand-Adaptive` |
| IP portrait | Uploaded portrait, recognizable visual anchors, or instruction to omit |
| Style reference | Reference images, palette, typography, density, and mood |
| Page count | Determined by content and the owner’s publishing habit |
| Title/body limits | Platform limit or account rule |
| Archive path | Workspace path, project folder, or no local archive |

## Owner Preference vs Generic Rules

Generic rules are fallback. The account owner’s confirmed finals and visual preferences win. Preserve the useful parts of an approved version; repair the specific problem and its underlying rule instead of redesigning everything.

## Client Mode and Privacy

- Replace owner-specific product names, internal paths, private cases, and portraits with client variables.
- Ask the client for an IP portrait and one to three style references when visual identity matters.
- Use the client’s real products, offers, cases, and platform limits only when provided.
- Never invent proof, income, screenshots, feedback, or platform rules.
- Never ship another owner’s portrait, name, contact details, product names, case names, or filesystem paths in a reusable client package.

## Page Count Guidance

```text
simple point -> fewer pages
normal tutorial -> 4-6 pages
dense list or full social set -> 7-9 pages
```

## Style Prompt: Personal-IP Doodle

```text
Create a 3:4 Chinese social image-note card in a distinctive personal-IP hand-drawn doodle style.
Use a pure white background, black marker-like linework, sparse bright orange-red and cobalt-blue accents, irregular handwritten Chinese typography, generous whitespace, and one clear physical metaphor.
Translate the uploaded portrait into a consistent drawn character using recognizable facial, hairstyle, glasses, clothing, and temperament anchors.
Let the character actively demonstrate the page idea when useful.
Keep visible text short, correct, and readable.
Avoid corporate infographic polish, generic templates, dense comic panels, fake claims, and malformed text.
```

## Style Prompt: Brand-Adaptive

```text
Create a 3:4 Chinese social image-note card in the account’s visual identity.
Preserve the supplied reference’s palette, texture, density, typography mood, and atmosphere without copying protected content.
Use the uploaded IP portrait on the cover unless recurring character storytelling is requested.
Make the cover informative and collectible; make inner-page layouts fit the content.
Avoid malformed text, fake claims, and unreadable small text.
```
