# Copy Rules

## Title

Separate the title from the body. Keep the title compact and practical. Use the platform limit when supplied; otherwise avoid decorative filler.

Useful patterns:

```text
topic + reader scene + concrete number
problem + practical route
result + time span + method
```

Avoid unsupported superlatives, “must install,” “magic tool,” “one-click guarantee,” and fear-based clickbait.

## Body Length

If no platform limit is provided, default to under 1000 Chinese characters including tags and CTA. A short image-card post should not be stretched merely because the platform allows more.

## Opening

Start from the reader’s real work scene:

```text
what the reader is trying to do
where they get stuck
why this note offers a usable first step
```

Avoid generic trend openings, empty AI hype, and formulaic “not X but Y” constructions unless the owner explicitly likes them.

## Item Descriptions

For every tool, method, step, or product element, explain:

```text
name
what concrete work it helps complete
who or which scene should try it
one practical boundary when needed
```

Prefer ordinary work verbs such as research, organize, write, compare, package, publish, review, and deliver. Avoid internal agent jargon that readers cannot understand.

## Tone

Practical, human, lightly opinionated, and easy to understand. Use complete logic without turning the body into a platform audit statement.

## CTA and Tags

For normal publishing, use a natural low-friction next step only when it grows from the content. For heating/recommendation, remove comment-number voting, forced following, private-message collection, QR codes, and tag walls.

## Cross-Platform Note

When mentioning tools, use the fixed expression if the owner supplied one; otherwise name only platforms relevant to the task.

Codex, Claude Code, and WorkBuddy can all use this capability, but installation, available image tools, and exact models differ by environment. Never claim that every platform installs the same ZIP in the same way or uses the same image model. When a platform has no native image generation, deliver the complete card map, page prompts, title, and body for the user’s available image tool.
