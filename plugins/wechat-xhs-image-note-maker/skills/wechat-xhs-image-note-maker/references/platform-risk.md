# Platform Risk

Use this file when the user mentions:

```text
加热
推荐
公众号贴图号加热
小红书加热
薯条
审核未通过
不符合推荐运营规范
```

The goal is one shared version that can run on both WeChat image post and Xiaohongshu image note when the user wants a single set.

## High-Risk Combinations

Risk rises when several of these appear together:

- list title looks like third-party tool promotion
- many tool, plugin, CLI, or AI product names are stacked
- "必装", "神器", "最值得", "一键搞定"
- "降 AI 味", "隐藏 AI 痕迹", "改得像真人"
- "批量生成", "自动发布", "批量搬运", "脚本托管"
- "评论区丢数字", "私信领取", "转发", "关注", "扫码"
- tag wall
- claims that sound like guaranteed efficiency, money, traffic, or conversion

## Repair Strategy

Do not flatten the post into a compliance memo. Repair the risky parts while keeping the useful content.

| Risky direction | Safer direction |
|---|---|
| 最值得安装 / 必装 | 新手清单 / 我常用 / 值得先看 |
| 神器 | 适合用来 / 可以辅助 / 能减少重复工作 |
| 降 AI 味 / 改得像真人 | 把生硬中文润顺，保留自己的语气和判断 |
| 批量生成大量视频 | 做固定模板的视频内容 |
| 自动操作电脑 | 处理自己有权限的低风险流程 |
| 评论区丢数字 | 后面继续拆几个具体场景 |
| 私信领取 / 扫码 | 删除或改成自然收尾 |

## Computer Use and Automation Boundaries

When a tool can operate a browser, computer, workflow, or business app, add a practical low-risk boundary:

```text
先从自己的固定流程试。
只处理自己有权限的资料。
别一上来碰高风险动作。
```

Do not write the public post as if the agent can freely control third-party platforms, bypass rules, scrape private data, or automate posting.

## Tool-List Notes

If the original note is a tool list and the list format is valuable, it can remain a list. The fix is not always to hide the list.

Keep:

- clear item names
- useful newbie explanations
- high-density cover
- practical scenes

Reduce:

- promotional framing
- exaggerated ranking
- interaction bait
- risky automation language
- dense tags

## Review-Failure Repair Flow

1. Read the platform failure reason.
2. Identify whether the risk is title, body, image text, CTA, tags, or all of them.
3. Preserve the parts that performed well on the other platform.
4. Rewrite public copy first.
5. Regenerate only the images that visibly contain risky or wrong text.
6. Validate the final title/body length and image set again.

## Reader-Facing Endings

Avoid endings written for the platform auditor, such as:

```text
本文不涉及平台规则外动作……
```

Prefer endings that help the reader:

```text
建议先存着，用到哪块再看哪块。
后面我会继续拆资料、文档、表格、网页和视频几个具体场景。
```

If the post is in strict heating mode, do not add comment-number voting.
