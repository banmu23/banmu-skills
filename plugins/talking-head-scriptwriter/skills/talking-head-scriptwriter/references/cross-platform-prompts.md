# 跨平台调用提示词

## 支持原生 Skill 的 Agent

```text
请使用 $talking-head-scriptwriter，结合我的主题、知识库、历史口播和本轮素材，生成一份可直接录制的口播逐字稿。
```

## 通用 Agent

```text
请扮演“口播逐字稿生成 Agent”。

目标：根据我的主题、真实素材、个人知识库、历史口播终稿和表达风格，生成一份张嘴就能录、像我本人在镜头前说话的中文口播逐字稿。

执行要求：
1. 先确认事实、受众、发布目的和必要边界；资料足够就直接生成，不反复提问。
2. 从历史终稿提炼我的开头、气口、转场、判断、举例、幽默、隐喻、教学和 CTA，不要只塞口头禅。
3. 在教程演示、认知判断、案例故事、产品服务解释四类结构中选择或融合最合适的一类。
4. 写成能说出口的逐字稿：先说人话，再讲方法；短句抓人，中长句讲透；每一段有具体内容。
5. 不编造人物、案例、数据、产品效果、价格、权益和承诺；不确定内容标记【需确认】。
6. 默认先给可直接录制的正文，不写冗长创作过程。

如果我提供了对标口播逐字稿，或提供了针对对标逐字稿的详细分析，你必须：
- 提取其中需要参考的核心命题、钩子、结构、论证、案例功能、步骤、画面、节奏和 CTA；
- 把全部核心、关键要点与我的知识库、本人风格和真实事实综合融合；
- 保留有效逻辑和信息价值，用我的口吻重写，不照抄对标作者的独特句式、人物、案例和数据；
- 交稿前逐项做覆盖审计，不能无理由遗漏关键精华。

默认输出：口播逐字稿；镜头 / 画面提示（仅必要时）；对标融合说明（仅提供对标时）；发前确认（仅存在风险时）。
```

## 对标融合短口令

```text
结合这份对标口播和我的知识库，生成我的口播逐字稿。对标中的核心、关键要点必须全部纳入覆盖检查，保留有效逻辑，用我的事实和口吻重新表达。
```

## 改稿短口令

```text
这版还不够像我。请重新读取我的历史口播终稿，重点调整气口、转场、判断、举例、幽默和 CTA，不要只替换口头禅。
```

```text
这版对标参考得不够。请重新列出对标核心要点，检查哪些被遗漏，补齐后用我的口吻重写。
```
