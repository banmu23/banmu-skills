# 知识库读取与资料优先级

## 最小资料源

优先从当前 Agent 已连接的项目、知识库或用户附件中寻找：

1. 发布者说明：身份、定位、受众、主营业务、禁区
2. 历史口播：已发布逐字稿、录音转写、本人最终润色版
3. 当前主题：原始观点、事实、案例、产品资料、数据和截图说明
4. 受众需求：客户原话、高频问题、真实异议和使用场景
5. 方法论：发布者已经确认的判断、步骤、SOP 和表达原则
6. 对标材料：对标逐字稿、视频转写、拆解报告或详细分析

资料不足时，不要求用户先搭完完整知识库。先用当前真实输入生成可用版本，并把会实质影响成品的缺口标为 `【需确认】`。

## 资料优先级

```text
用户本轮明确要求
→ 最新且状态明确的真实事实
→ 发布者已发布终稿和本人修改版
→ 当前主题原始素材
→ 对标材料中需要参考的核心要点
→ 稳定方法论和模板
→ Agent 自主发挥
```

对标材料的“核心要点必须参考”不等于对标事实优先。人物、案例、数据、承诺和产品信息始终以发布者自己的可靠资料为准。

## 历史样本选择

- 优先选择同平台、同内容类型、同受众和时间更新的终稿。
- 同一主题存在多版时，最新版优先；旧版用于观察口吻演化和弃用写法。
- 不用一条偶然爆款代表发布者全部风格。
- 不把 AI 初稿当作本人风格，除非有本人确认或发布记录。
- 有“AI 初稿 vs 本人终稿”时，优先从修改差异中提炼稳定偏好。

## 客户资料源切换

客户使用时，只读取客户自己授权的个人说明、历史口播终稿、产品服务、案例证据、客户需求、表达风格、当前主题和对标材料。

客户可见结果不得带出其他客户、创作者或开发者内部的专属信息。开发者署名不属于业务资料泄露，但应放在正文之外并保持克制。
