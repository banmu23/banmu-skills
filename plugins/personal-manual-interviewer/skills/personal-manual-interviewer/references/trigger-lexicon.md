## Soft Triggers

Use this Skill if the broader task asks to collect or clarify:

- Who I am.
- Who I help.
- What I sell.
- How I make money.
- How customers find me.
- Why customers trust me.
- How I speak.
- What AI should know before helping me.

## Do Not Trigger When

Do not use this Skill if the user only wants:

- A one-off bio rewrite.
- A single social post.
- File sorting.
- Screenshot organization.
- Platform setup.
- A generic business plan with no personal manual intent.
- Content writing unrelated to building a reusable background document.

If unsure, ask one short question:

```text
你是想让我直接写这一段介绍，还是想顺手整理成以后 Agent 都能用的《个人说明书》？
```

## Trigger Boundary

Do not require the user to say the exact Skill name.

If the intent is clearly “help me explain myself to future Agents,” use this Skill.

If the intent is only “write something for public posting,” do not force this Skill.
