# Interview Flow

Use this reference when guiding the user through the interview.

## Tone

The user should feel:

```text
有人在陪我慢慢梳理
我可以随便说，不用一次说对
我不用懂专业词
我只要回答几个小问题
```

Do not sound like:

```text
问卷
考试
审问
商业咨询报告
复杂提示词训练
```

## Opening

Start with a soft promise:

```text
我们先不用追求完整。
你想到哪里说到哪里，我会负责帮你补结构、抓重点、整理成能长期用的版本。
```

Then ask the four starter questions:

```text
1. 你平时会怎么介绍自己？随便说，不用正式。
2. 你主要想帮哪类人？
3. 你现在主要卖什么，或接下来想靠什么变现？
4. 你希望以后 Agent 最常帮你做什么？
```

If the user already answered one of these, skip it.

## Internal Coverage Map

Silently track these areas. Do not show this as a table unless the user asks for a progress check.

```text
identity: who they are, background, strengths, important story
people: who they help, who they do not serve, customer pain
offer: product, course, service, consulting, community, project, future offer
money: how they earn or want to earn, next monetization path, price if confirmed
trust: proof, cases, experience, credentials, results, customer feedback
traffic: how people find them, public content, private community, referrals, platform
sales: why people buy, common objections, decision path
delivery: how they help after purchase, process, boundaries, follow-up
voice: how they speak, phrases they like, phrases they dislike
agent_help: what the Agent should help with, what it must not invent or expose
privacy: private materials, public boundaries, names/screenshots/prices/results
next: current priorities, upcoming product, content, project, or business focus
```

## Follow-Up Rules

Ask at most 3 questions per turn after the first round.

Choose the next questions by priority:

1. Missing basics that block the manual.
2. Commercial positioning and how the person makes money.
3. Customer trust and real proof.
4. Delivery and boundaries.
5. Speaking style and Agent preferences.

Use plain questions:

```text
客户一般为什么会来找你？
他们最常卡在哪一步？
你帮完以后，他们通常会有什么变化？
你最不希望别人怎么介绍你？
哪些内容只能自己和 Agent 看，不能公开说？
```

Avoid stiff questions:

```text
请描述你的商业模式
请填写目标用户画像
请定义你的内容策略
请提供一套完整规则
```

## When The User Cannot Answer

Offer simple choices:

```text
没关系，这题可以先粗略选一个：

A. 他们主要是不会开始
B. 他们主要是做了但没结果
C. 他们主要是东西很多，但不知道怎么整理

你也可以直接说“都不是”，我再换个问法。
```

Offer sentence starters:

```text
你可以照这个句式随便改：
我主要帮【哪类人】，解决【什么卡点】，最后让他们能【得到什么结果】。
```

Let the user skip:

```text
这块先跳过也可以，我会在说明书里标成待补充。
```

## When To Generate

Generate a first full manual when:

- The four starter questions have enough answer substance; or
- The user asks to先生成一版; or
- You have at least rough information for identity, people, offer, money, voice, and Agent help.

Do not over-interview. A useful first version is better than making the user answer too much at once.

After the first version, ask:

```text
我先给你整理成一版完整说明书。
你看完以后，只要告诉我哪里不像你、哪里要补，我再帮你慢慢校准。
```

## Revision Loop

When the user corrects the manual:

1. Treat the user's correction as higher priority than your earlier inference.
2. Update the relevant section.
3. If the correction reveals a stable preference, apply it to the rest of the manual.
4. Keep the wording natural and easy to reuse.

Do not ask the user to rewrite the whole manual.
