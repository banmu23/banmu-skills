# Magazine Layout Rules

## Aesthetic target

Create a refined light-magazine feel:

```text
高级
干净
有呼吸感
适合知识 IP / 一人公司 / OPC 深度内容
```

Avoid:

```text
rough one-side quote borders
crowded text
tiny font
too many divider lines
unbalanced padding
template-heavy marketing style
```

## Defaults

```text
body background: #ECE5D8
page background: #FFFDF8
page max-width: 760px
mobile padding: 38px 24px 52px
desktop padding: 52px 38px 64px
body text: 17px
line-height: 2.0
main green: #184C3A / #123E31
border gold-brown: #D8C7A3
accent brown: #8A551D
text: #1E2B28
```

## Opening

Do not repeat the same title inside the body if the WeChat backend already displays title and author.

Begin with:

```text
result card
core event
first strong paragraph
first proof image
```

## Cards

Use full-border cards:

```text
light ivory/beige background
thin gold-brown border
10-12px radius
balanced top/bottom padding
subtle shadow
```

Single-line cards must look vertically centered.

Do not use empty `&nbsp;` paragraphs to create spacing.

## Headings

Top and bottom fine-line headings are allowed, but do not stack extra horizontal rules around them.

If a heading component already has lines, remove nearby independent dividers.

## Images

Images should:

```text
width: 100%
border-radius: 8-10px
subtle shadow
margin top/bottom: about 28-30px
```

Captions should:

```text
14px
centered
low-saturation brown/gray-brown
10-12px from image
explain what the image proves
appear below the image by default
```

Do not put captions above images unless the target editor technically forces it. In customer-facing layouts, image then centered caption is the default reading order.

## Visual self-check

Before delivery, check:

```text
Does the first screen waste space?
Are quote/cards vertically centered?
Are there too many divider lines?
Is body text too small?
Is page padding enough?
Are image captions useful?
Is the knowledge card near the end, before final guide?
Is the footer not cramped?
```

For long practical articles, the main overview knowledge card should usually appear in the minimum-loop / route-summary / follow-along section, or after the final main argument and before the closing guide. Do not place it randomly in a section where the reader has not yet reached the workflow summary.
