## 怎么使用

1. 在支持 Skill 的 Agent 中安装 ZIP；ZIP 根目录直接包含 `SKILL.md`。
2. 提供本次素材、配图及可访问的历史风格或知识库。可直接说：`朋友圈：根据这些真实素材写一条可发布的文案`。
3. Agent 按 F00—F11 流程核对事实、人物与结果、关键选择、图文关系和公开边界，交付正文并只列必要的发前确认。

资料不足时只追问影响事实和发布安全的缺口；已有决定沿用。支持哪些安装方式、工具和知识库读取能力，以当前平台实际条件为准。

## 安装与升级边界

按用户指定的全局或项目范围安装。首次使用如能联网，则检查公开版本；发现新版先说明变化并取得确认，再升级。检查失败不阻塞当前写作，不静默覆盖自定义文件、客户资料或账号配置。

公开包不含作者内部产品资料、私密案例、截图、密钥、本机路径或内部角色资产。用户提供自己的授权材料；只生成与检查文案，不自动发布朋友圈。
