# 用户自己的角色：首次必读

references/role-profile.json为本机私密运行配置，公开默认confirmed=false且无参考。向用户收集已授权的少量自有角色图、身份气质、服装/标志物、风格、肤色/比例和禁忌；必要时安装合法基础能力并魔改为用户自己的角色。关键新名称和风格由用户确认，已有选择不重问。角色与授权方案确认后写confirmed=true并登记owner_id/family/主锚图和必要参考；先用validate_assets.py --require-ready --trial检查试图条件，真实试图验收后才写trial_passed=true，再进入正式正文。不能用作者形象或通用角色充作用户自有角色。

角色外貌完全来自用户确认，不预置作者脸形、发型、穿搭或配饰。人物数量与关系由当前配置决定，sole_human是可调整的单主角默认而非作者人物设定；多角色必须有具体内容职责与确认关系，不自动补陌生搭档。非人辅助也不为装饰硬加。

表情是同一角色的表演，按内容改变眉眼/嘴型/视线/身体反应，夸张有趣但不换脸或气质。参考服从确认身份；场景丰富、材质、纵深和自然光影按用户已确认审美执行，已有好场景定向修改并保护其余部分。
