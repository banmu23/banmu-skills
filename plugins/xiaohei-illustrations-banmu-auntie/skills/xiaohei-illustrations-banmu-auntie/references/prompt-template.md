# 生成与定向修改提示词

调用前填实：原文依据、唯一purpose、anchor/placement、内容场景与物理动作、表情（情绪/眉眼/嘴型/视线/身体）、光影（主光/层次/材质/纵深/接触影）、精确短labels、角色与参考职责、edit_mode/preserve。用用户已确认角色配置构造完整独立提示词，不带作者角色特征。

新建：主参考固定同一角色，其他参考只提供本张需要的表演/结构/质感；按具体正文设计丰富且有解释价值的场景，清楚动作/因果与中文，输出一张独立16:9高质量PNG。不要复制参考分格/环境、PPT/流程卡或无关标题。

局部编辑：先看并实际传入原始好图和自有身份参考。“只改[指定项]为[具体眉眼嘴型/视线/身体反应]；保留已通过的[场景/环境/材质/光影/构图/身份/标签]，不重画正确区域，不增人物/道具/口号。”生成后整张复核而不只看局部。多轮损质回原始图与主锚重做。完整实际提示词、参考输入与调用结果须保存，模板不能充作调用证据。
