# 逐节点执行、云端交付与断点

严格执行流程图.md / workflow.json：S01来源→S02身份能力→S03覆盖→S04解释及锚点→S05场景/保护→S06表演光影→S07真实生图→S08逐图QA→S09整组复核→S10依授权交付→S11位置/客户呈现→S12如实完成。只有要求维护Skill时执行M01–M06版本安装发布，不把每次出图自动扩成Skill发布。

任务模式记录：仅方案、本地PNG、编辑当前已授权在线文档、另建图文副本。用户已要求哪种就执行哪种；不自行改成新建，也不把生图/写文档授权推成公开分享/发消息。仅方案在清单/提示词阶段交付，明确图未生成；能力不足保留独立可推进工作与断点，不用程序图顶替。

云端写前读取最新目标，保存原正文、原图、附件、表格、链接、导航与人工结构。要求副本才新建，立即记录目标ID并恢复同一目标；原文只读。要求当前文档优化则仅改授权项，保留资源与确认内容。超时先回读，防重复创建和重复插图。

美化结构先稳定，复用所有可用原图后插入通过的生成图。按purpose与准确anchor/placement紧贴关键段落或表格之后，不塞表格单元格、不平均间隔、不堆文末。客户正文没有来源/制作标注；必要的操作解释可保留。source原图/生成图数量分别核对，不能只看总数。

写后全文回读，逐图核对本地PNG、云端资源、位置、比例和前后衔接；约760px等比例显示，以真实阅读清晰度为准。实际看页面或服务端渲染，写明预览方式和页数/范围；没做网页/手机测试就不声称做过。核对原图/附件/表格/链接/人工结构都保留后，才记对应范围完成。

每完成生成、返修、插入、QA更新run.json。恢复读取真实来源、当前文件/云端及剩余项，不凭聊天摘要推定通过；run模板空值不能充作证据，旧记录版本迁移按maintenance.md。脚本仅查记录完整性，不能代替真实看图/调用/平台验证。只报告本次实际完成范围。
