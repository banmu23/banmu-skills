# 飞书一键转 ima 知识库 · V1

提供飞书知识库首页链接，用一句口令启动转换。Agent 会按原目录建立 ima 文件夹，导入原飞书链接，并制作根目录实操手册、一句话描述和品牌封面。成员权限单独验收，未确认生效就不会报告完成。

## 第一次使用

1. 把 `feishu-to-ima-kb.zip` 上传给支持 Skill 导入的 Agent，按当前平台提示安装。ZIP 已直接包含 SKILL.md，不需要客户手动运行安装脚本。不同平台是否支持 ZIP 导入，以该平台当前能力为准。
2. 让 Agent 检查已连接的飞书、ima、生成图片和查看图片能力。已有连接直接使用；缺登录/本人授权时，按当前一步指引操作。密钥只在安全配置中填写，不发到聊天。
3. 发送下面这段话，并换成自己的链接。源中未写明联系方式时，补上自己的联系方式即可。

> 使用【飞书一键转 ima 知识库】Skill，把这个飞书知识库转成对应的 ima 知识库：我的首页链接。描述中的联系方式使用：我的微信。通过已连接的 API 操作 ima，保留原模块和原链接，根目录放实操手册，生成封面，成员内容可查看但不可导出。逐项验收，缺项不要报完成。

正常结构的普通技术步骤由 Agent 完成。遇到特殊层级、重复链接、同名目标或确实缺少品牌信息时，才需要你做关键选择。选过的不会反复问。

## 你会得到什么

- 根目录第一入口：先看这里｜ima 知识库实操手册。
- 与原飞书二级模块对应的一级文件夹。
- 相应文件夹中的原始飞书链接，保留真实地址。
- 根据你的真实内容写的一句话描述和自己的联系方式。
- 实际生成、设置并检查过在线缩略图的封面。
- 权限真实结果、完成者及必要的待完成项。

## 关于权限和飞书原链接

当前 V1 没有提供经过验证的默认权限写入接口。如果当前 Agent 的连接也不能设置并实际读回权限，Agent 会把其他可自动完成的工作做好，再请你在 ima 本库权限中设置【内容可查看，但不可导出】。保存后明确告诉 Agent 实际结果，Agent 才能标记客户手动完成；接口返回成功不能代替这个环节。

原链接仍受飞书原文权限控制。加入 ima 不会自动取得飞书访问权，也不代表 ima 已读懂私有文档全文。是否成功解析由 Agent 实际检查。需要邀请客户加入时，使用 ima 当前真实分享入口；拥有者访问地址不能冒充公开加入链接。

## 中断后继续

> 继续上次飞书转 ima 任务，读取原运行记录和实际知识库，只补未完成项，保留我的人工修改。权限没有实际证据不要报完成。

保留 Agent 的运行记录以便恢复。不要删除运行状态后重做；否则无法可靠判断哪些资源已经创建。涉及无法确定结果的写入时，Agent 会先核实，不盲目重试。

## 支持范围

标准结构为首页→模块→资料，目标为根目录手册＋一级文件夹→二级原链接。更深目录、正文内链接集合、同名标题、重复链接需要先明确处理方法。V1 已在 Codex/macOS 开发并完成模拟故障测试和原案例线上只读核验；其他 Agent 平台尚未逐一实测，不承诺缺少连接能力的普通聊天能直接建库。
