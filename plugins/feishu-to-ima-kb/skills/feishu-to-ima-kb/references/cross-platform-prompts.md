## 平台事实

- Codex：V1 在 macOS 已有 Python、lark-cli 和 ima 连接环境开发；开发验收记录区分模拟写入、线上只读和此前真实案例。新脚本没有冒充独立全流程线上写入测试。
- Claude Code、Hermes、Workbuddy：有 Skill 加载、Python/等效执行、飞书与 ima 授权、生图及图像查看能力时可按相同流程调用；V1 未逐一实测，不宣称开箱全自动。按实际平台提示导入英文 ZIP，若不支持 ZIP 则使用该平台文档规定的 Skill 安装方式。
- ChatGPT：可使用说明和规则；只有当前会话确有相应连接器/执行和生图能力时才可执行建库。普通对话不能凭读到 SKILL.md 就声称已操作 ima。
- ima 对话本身：本 Skill 的产物在 ima；ima 聊天能否加载 Skill 和调用外部接口需当前环境验证。不能把“上传了这份 Skill 文本”说成已安装可执行连接器。

缺少能力时说明当前具体缺口，保留已经完成的内容。客户只需要提供资料和必要本人授权，普通脚本操作、分页与校验由 Agent 执行。
