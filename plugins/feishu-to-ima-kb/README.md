# 飞书一键转 ima 知识库 · V1

将已经做好的飞书知识库转换为对应的 ima 共享知识库，客户打开根目录手册就能知道从哪里学、如何打开资料和怎样实践。

## 一句口令开始

> 使用【飞书一键转 ima 知识库】Skill，把这个飞书知识库转成对应的 ima 知识库：我的飞书首页链接。通过已连接的 API 操作 ima，保留原模块标题和原始链接，根目录放简明实操手册，制作描述和品牌封面，成员内容可查看但不可导出。缺少实际证据不要报告完成。

首次使用前，请让 Agent 检查已授权的飞书、ima、生图与图像查看能力。普通技术步骤由 Agent 执行，缺登录时客户只完成本人必要授权。全程不通过屏幕共享或电脑控制操作 ima。

## 交付结果

- 原首页改写为根目录第一入口实操手册。
- 原二级模块标题对应 ima 一级文件夹。
- 原三级资料的飞书链接直接放入对应文件夹，保留实际地址。
- 来自真实资料的一句话描述与客户自己的联系方式。
- 真实生成并设置、检查过实际在线缩略图的品牌封面。
- 原 URL、归属、数量、笔记、入口、封面与成员权限的独立验收记录。

## 当前支持边界

V1 标准执行器支持两层目标结构及同任务断点接续。更深目录、正文内链接集合、重复 URL 或同名目标需要先确定实际处理方案；不会静默删减或覆盖人工修改。原飞书资料仍受飞书访问权限控制，导入链接不代表 ima 已读取私有全文。

当前默认权限自动写入接口未验证。当前连接不能设置并实际读回时，Agent 会保留缺口，由客户在 ima 保存【内容可查看，但不可导出】并明确反馈，标为客户手动完成。接口 code=0 不等于设置生效，不承诺全过程无人操作。

本版已完成 24 项模拟故障测试、原案例线上只读核验及包结构检查；新执行器未独立做全流程线上写入测试，其他 Agent 平台未逐一实测。具体能力取决于当前平台实际连接。
