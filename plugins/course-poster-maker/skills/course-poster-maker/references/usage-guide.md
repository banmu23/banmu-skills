# 课程海报一键生成 · V2 使用说明

把课程文案和已有素材交给Agent即可。参考海报、个人形象照、简介、Logo、案例与好评截图都按需要提供，不要求一次备齐。

可以这样说：

> 使用课程海报一键生成，参考我上传海报的排版、色彩和质感，为我的课程制作长海报。课程文案见附件；人物照和简介也已上传，请先判断怎样安排最合适。

> 使用课程海报一键生成，把介绍和大纲合成一张，重点突出权益与交付路径，不放导师简介。

> 使用课程海报一键生成，只修改这张海报右上角英文。主标题、其他文案、段距和案例图全部保留，不要越改越糊。

Agent会先读资料与真实图片，核事实和参考用途；只确认必要信息，然后按12节点规划、制作、实际检查并交付。你可选“分开做两张（主海报＋大纲海报）”或“合成一张长海报”，也可明确不展示大纲。普通客户无需运行脚本。

可增加“能获得什么”、案例成绩、好评／学员怎么说、导师等板块；提供了资料并不意味着全部必须上图，Agent会按课程重点推荐。参考图的设计可以学习，参考图里的价格、人物、成绩和承诺不会自动搬到你的海报。提供照片时保留真实身份；提供截图时按用途脱敏并保持证据真实。

会优先使用当前平台的原生生图或图片插件。中文长文或真实素材需要更稳定排版时，Agent说明原因，按确认路线采用素材组合、HTML或混合方案。HTML路线会同时交可编辑源和正式长图。

更新已有海报时，明确“哪些改、哪些保留”；已认可的部分会冻结，必要时从清晰原稿重建。预览用于快速检查，最终使用完整原图。图片分辨率太低或信息过密时会说明具体限制，不假称恢复不存在的细节。
