# 提示词与制作记录

P06先写方案，以下按需填，不把缺失项目作为客户必填问卷。提示词不是完成证据；P07/P08保存实际调用与结果。使用已有原生素材时保存源与复用变换，不伪造本轮提示词调用。

```text
用途：课程主海报／大纲海报／指定局部素材
图片角色：图1是风格参考；图2是客户人物；图3是编辑目标……
原子文案：逐条完整粘贴本图已确认文案，不改事实和限定词
设计重点：本课程最重要的价值／权益／交付，弱化哪些信息
参考迁移：采用的色盘、材质光影、层级、节奏、自然转场；不采用的无关内容
全局布局：版心／边距，主标题与说明组，同级标题副标题，正文、段距
素材：人物真实身份和光向；Logo的中英关系；真实证据仅预留合理位置，另走保真合成
画布与用途：目标阅读尺寸、长图信息量、工具实际能力
改动范围：只改哪些；冻结哪些；不得恢复已删除板块
约束：中文清楚、术语易辨、无错字、无拥挤、无变形、无脏纹理；不重画证据
```

有客户照片时说明真实身份保留，不借参考人物；无照片不强加人物。参考只换材质／配色时不要顺手重排。需要AIP等术语清楚时，明确可读字形与适当词距，不承诺模型精确像素对齐。精确位置由成图核验决定。

P12交付时提供原图、实际尺寸、简短改动说明、具体局限（若有）；提示词／原生来源可作为制作记录链接，不把本地内部备注写进海报。
