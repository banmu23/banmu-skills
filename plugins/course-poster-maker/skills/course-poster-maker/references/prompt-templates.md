# 原生生图提示词结构

这些是结构提示。所有变量从本次已确认资料填写，不在模板中内置历史价格、权益、人物、课程名或名额。

## 共享设计母版

```text
用途：完整课程主海报，{一张 / 两张中的第几张}。
目标与定位：{真实课程定位与阅读场景}。
参考角色：图A为{授权风格参考 / 编辑目标}；图B为{已通过首图 / 支持素材}。
画布：{本次决定的比例与尺寸目标}。按内容留足高度；不要为了固定比例压缩字体。
风格：{已确定风格}。默认精致手绘3D浮雕黑板粉笔风，简单深色胡桃木框，干净深黑板面，精致可信材质和自然层次。多种高级撞色，精致而不艳俗。
文字：中文是高优先级，精确逐字呈现，笔刷/涂鸦字灵动且清楚。正文厚实精致，正常比例，不拉长、不压瘦、不失真。标题无粗糙毛刺。
排版：先按下面的信息结构规划再绘制；版块清楚，标题突出，权益与大纲分别突出。留足行距、边距和模块间距，清晰易检索。
图形：每个图标直接服务相邻内容；少而准确，不以装饰挤占文字空间。木框简单精致，不加繁复装饰。
色彩与材质：{锁定底色、字色、主/辅助色、木框和浮雕光影}。黑板干净，不蒙灰、不脏；禁止黄咖啡色污染、过度做旧、塑料感。
逐字文案：{本张完整确认文案，保持层级；不可缺字或擅自改写}。
重复限制：{仅显示一次的段落及本张是否承载它}。
禁止：遗漏条件/数字/单位、编造内容、补造人物/Logo、模糊小字、遮挡、乱码、变形、内部制作标注。
清晰度：请求原生工具当前可提供的最高合适质量；实际像素和可读性在生成后验收。
```

## 介绍页 / 无大纲单图

明确标题、副标题和各个内容块的顺序；长段落可拆行为阅读分组，但不删事实。先列关键结果/价值，再列权益等真实内容。已有价格、人群、讲师、报名均在本张。给权益区明确面积和足够字重，不能全图只剩大标题醒目。

双图时尾部用简短导航衔接“下一张：课程大纲”；单图时不添加不存在的下一张、02/02 或虚构课程内容。

## 第 2 张大纲页

```text
这是同一课程的第2张课程大纲海报，引用已经通过验收的第1张作为视觉母版。
严格匹配其黑板底色、木框、标题字重、配色、光影与精细程度；不能偏黄或偏咖啡色。
课程大纲是本张主角，保留全部模块、模块内小点与学习顺序；不把正文压成只剩模块标题。
根据条目长度选单列、两列或分组，不机械两栏。大纲正文厚实、清楚、不细瘦、不拉长。
仅保留必要课程题名、02/02与承接提示；不搬入人群、价格、权益等介绍页信息。
完整逐字大纲：{确认大纲}。
```

## 定向修改

```text

仅允许修改：{精确文字、版块、表情、颜色等本次指定项}。
必须保持：{其余文案、图案、材质、边框、字号、构图、配色、品牌等逐项列出}。
修改前文字：{如适用}；修改后文字：{确认原文}。
保持原有清晰度与质感；不要重新发挥其余部分。
```

修改完检查所有文字与锁定项；生成式编辑不能保证逐像素保留，未保持即返工，不以“只改一处”的提示词代替实际核验。
