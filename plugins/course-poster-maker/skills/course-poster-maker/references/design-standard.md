# 课程主海报设计标准

## 内容先行

读课程的真实定位、服务对象与学习路径，先规划信息，再排版。每个文案事实和大纲小点均进入对账清单，不能丢限定词、数量、单位或条件。不经许可不删减、概括替换完整大纲，也不追加效果、资历和收益承诺。

有大纲：第 1 张为课程介绍，放价值、权益、讲师、人群、时间、价格和报名等已有信息；第 2 张主要完整展示大纲。第 2 张仅有必要题名、页码和衔接，不承接第 1 张放不下的商业信息。没有大纲就一张完整介绍图，不为分图造大纲。

核心完整承诺段只出现一次；如果另做视觉化要点，必须服务快速理解，不机械重复整段。原文重复编号可校正为清楚的顺序，不顺手改写业务事实。材料是课程清单时保留真实身份；只有用户明确指定时才按大纲页路由。

## 默认基准：精致手绘 3D 浮雕黑板粉笔风

| 项目 | 应达到的效果 | 需要返工的表现 |
|---|---|---|
| 整体 | 与课程定位一致，精致、有质感、吸睛，信息层级清晰 | 好看但漏信息；杂乱促销感；套壳而忽略课程内容 |
| 黑板 | 干净的深黑/墨绿黑，细腻而受控的粉笔肌理 | 灰蒙、脏兮兮、污渍、过度做旧、大片灰尘 |
| 木框 | 简单精致的深色胡桃木，可信木纹、接触阴影和空间感 | 粗重复杂装饰，占掉正文空间；整图变咖啡色 |
| 立体感 | 细腻 3D 浮雕、克制光影、可信材质 | 廉价塑料质感、夸张描边、字形被浮雕挤坏 |
| 色彩 | 多种高级撞色，有层次且不艳俗；默认可用奶油白、金色、青绿、砖红等 | 满屏高饱和杂色；第二张偏黄/咖啡色；两图色温不一 |
| 标题 | 大、醒目、灵动手写笔刷/涂鸦，边缘干净可辨 | 毛刺粗糙、破碎、拉长、压瘦、乱码、假书法 |
| 正文 | 手写气质但字形正常、厚实精致；清楚、足够大 | 字体太小、偏瘦、变形、字行重叠，靠挤压塞入 |
| 章节 | 版块分明，章节牌与编号便于检索，行距与间距有呼吸感 | 多层边框叠加；主次平铺；每块都争抢视觉 |
| 重点 | 权益与课程大纲各自突出，关键词少量强化 | 所有字同等醒目；只突出价格而看不清课程内容 |
| 图标 | 直接对应知识、路径、工具、交付等内容；简洁且精致 | 无关贴纸堆满；图标挤占正文；机械复制旧图道具 |
| 套组 | 同一风格母版、相同画布、统一材质、色调、字体与精细度 | 两张像两个独立产品，边框/字重/清晰度不一致 |
| 衔接 | 合理页码和前后文导航，形成完整课程表达 | 分页割裂；引导内容与实际第二张不符；错页码 |

用户明确指定其他风格时，将对应材质/配色项替换为该风格要求；完整文案、清晰字体、重点突出、套组一致和真实验收仍保留。不要未经询问引入私有角色、其他品牌 Logo 或人物关系。

## 字号、长度和高清

- 不锁定 9:16。长文可用 9:21、更长或当前工具支持的合适比例。双图默认同尺寸；按较长一页定共同高度并合理调配空间，不能用大段空白凑尺寸。确需异高说明原因再确定。
- 从手机阅读尺度倒推正文；先减无关装饰、优化分组、增加高度，再评估字号。不能用细小字、变形字解决拥挤，也不能为固定两张偷偷删信息。
- 在大纲页保留模块与具体小点的学习关系，不机械两列。短条目可两列；长条目优先单列或分组大区块，防止错读顺序。
- 将中文当高优先级文字处理，逐字核对复杂汉字、数字、英文、单位、标点和限定词。“矢量般清晰”是目标，栅格海报不能冒称有真实可编辑矢量图层。
- 4K/打印级是质量目标。打开真实文件核查像素与笔画；原生返回达不到时如实报告。不能把插值放大、DPI 元数据或“高清”文件名当作真实 4K 清晰度证据。

## 真正验收

1. 逐图打开原图，查看整图构图和文字局部；在约 390–430 像素显示宽度下实看正文，能正常阅读。
2. 逐条核对原子清单，记录每项在图中位置和结论；OCR 可辅助发现漏字和重复，但它读对不等于人眼能读。
3. 两张并排实看，核对底色、木框、金色、白字、辅助色、标题、字重和细节质量。
4. 扫描全套：正确页数；大纲分配正确；价格/人群在第 1 张；完整承诺段仅一次；无内部标注、错字、遮挡、变形与未确认信息。
5. 修改后既查指定改动，又查所有保留项；无法保持时回可靠母版，不声称逐像素不变。

生成成功、上传成功、脚本通过、OCR 通过都不能代替以上验收。失败定位到节点，修复后重查受影响图与整套。
