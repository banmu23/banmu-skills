# 课程海报一键生成 · 使用说明

## 你会得到什么

有课程大纲：两张互相衔接的课程海报，第 1 张介绍课程，第 2 张主要呈现大纲。没有课程大纲：一张完整课程海报。默认精致手绘3D浮雕黑板粉笔风、简单深色胡桃木边框；可使用你明确指定的风格。

尺寸按内容安排，可长于9:16。实际模型、精确尺寸、最大高度和清晰度以当前 Agent 的原生能力及返回原图为准。生成后逐字与目视核验；不保证每次一次生成零错字，不保证任意平台都能原生生成4K。

## 安装与调用

在支持 Skill 上传的 Agent 中上传 `course-poster-maker.zip`，按平台界面完成安装；ZIP 根目录直接含 SKILL.md。支持 GitHub Plugin 市场的平台也可从唯一正式源 <https://github.com/banmu23/banmu-skills> 安装对应入口。当前平台若不能安装或没有原生生图能力，Agent 应明确说明，而不是声称安装就能画图。

调用示例：

> 使用课程海报一键生成，基于附件里的课程文案、大纲和参考图制作海报。先按流程整理文案和排版，再用当前可用的最强原生生图能力制作。有大纲两张，大纲以外信息放第一张；没有大纲只做一张。尺寸按内容，可比9:16更长。完成后逐字与目视核验。

Codex 可直接调用 `$course-poster-maker`。普通工具操作和检查由 Agent 完成，无需客户运行脚本。

## 最少准备这些资料

| 资料 | 怎么提供 |
|---|---|
| 课程文案 | 粘贴或附件；标题、价值、权益、人群等真实已有内容 |
| 课程大纲 | 有则提供模块和具体小点；没有就说明没有 |
| 商业信息 | 只提供本次确实要写进图、且已经确认的价格、时间、权益、名额、报名方式 |
| 视觉参考 | 自己有权使用的参考图、Logo、照片；没有则按默认基准生成 |
| 修改要求 | 指出改哪张、改哪一处、哪些保持不动 |

不需要为模板补齐不存在的商业信息；不确定内容先核实，不能让 Agent 编造。客户资料、图片和活动信息留在客户自己的任务目录，不塞回公开安装包。

## 跨平台调用

对 Codex、Claude Code、ChatGPT、Hermes、Workbuddy 或其他支持 Skill 的 Agent，统一使用上面的调用语句，并要求先核验是否具备原生生图和参考编辑。模型选择按运行当下的官方资料和实际可用入口；示例模型名不是固定依赖。缺少能力时说明具体限制，按用户选择继续，不自动配置密钥或切换付费API。

## 修改与验收

修改时说“仅修改第几张的哪一段，其余保持”。Agent 会先看原图、锁定保留项，再实际编辑与核对。验收看完整文案、清楚中文、正确分图、统一风格、没有脏污和拉长字；同时看真实像素，不能只看“4K”文字说明。最终交付原图，并保留可接续记录。

新版本先展示变化，经你确认后升级；不会静默覆盖客户素材或知识库。
