# 课程海报一键生成 · V2

把真实课程文案与客户上传的参考海报、照片、简介、品牌和案例素材，转为精致清楚的课程长海报。可选一张整合，或主海报＋大纲海报；既有选择沿用，不固定风格和必填板块。

[下载V2英文ZIP](https://raw.githubusercontent.com/banmu23/banmu-skills/main/packages/course-poster-maker/V2/course-poster-maker.zip) · [使用说明](GUIDE.md) · [12节点流程图](skills/course-poster-maker/references/workflow.md) · [版本公告](../../versions/course-poster-maker.json)

先读真实图像，拆解参考的排版／色彩／材质，再规划全局层级、人物与真实证据。截图按用途脱敏、保留上下文，不能让模型重画。已认可区域冻结，修改回可靠原稿；不把0像素变化当作可读性证明。

优先当前Agent原生生图或图片插件，工具不支持时说明限制，按授权路线使用素材组合、HTML或混合方案；可编辑路线同时保留源。型号、尺寸和跨平台状态如实记录。

V2通过79项记录／像素边界测试、已有真实长海报与定向修改回归，并独立完成3种请求的规划试跑。规划不等于成图：本次没有新增生图、人物成图或HTML渲染实测；WorkBuddy／豆包工作／Claude Code为流程设计适配，未宣称实跑通过。

ZIP根目录直接含SKILL.md；不含客户素材、私聊、专属人物、内部路径或历史业务事实。质量、事实、隐私先于Token节省。客户设备升级先展示变化并确认，不静默替换。
