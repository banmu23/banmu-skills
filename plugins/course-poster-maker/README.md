# 课程海报一键生成 · V1

根据真实课程文案、大纲和授权视觉参考，制作精致、清楚、内容完整的课程主海报：有大纲两张（介绍页＋大纲页），无大纲一张。第1张放大纲以外的信息，第2张主要完整呈现大纲。

默认精致手绘3D浮雕黑板粉笔风、简单深色胡桃木框和高级撞色。先规划信息，再原生生图，按P01–P12逐项核对文字、真实原图和全套视觉，不以生成回执替代验收。比例随内容，可超9:16，实际尺寸以当前原生入口为准。
