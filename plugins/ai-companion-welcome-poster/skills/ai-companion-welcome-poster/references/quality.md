# 成图验收：真实看图后才能填写

每张检查原图与约390像素宽预览。预览仅用于检验常见手机显示尺度，不能冒充实际微信发送测试。禁止将所有项目默认设为通过。

| 检查项 | 通过要求 | 失败动作 |
|---|---|---|
| 文案逐字 | 昵称、同学、每个身份/地域、编号与事实卡一致，固定文案与profile一致 | 从原母版重做，明确错误字 |
| 编号 | 四个数字全部正确，包括前导零；“号”为母版手写，令牌框无重构 | 重做，不猜OCR识别结果 |
| 旧信息 | 整图不含无原文依据的旧昵称、旧身份、旧地名或旧号 | 查完整字段地图，回原母版替换遗漏区 |
| 头像 | 主体、真实脸型/五官/视线或插画配色/纹理相符，未错误换人、真人化或美颜重塑 | 对照输入，明显漂移则重做；不能称已无损嵌入 |
| 固定区 | 品牌、slogan、主句、印章、价值区与图标、页脚、末笔、手与背景保持母版视觉特征 | 明显重排/删字/图标变化即失败 |
| 版式 | 模板A/B一致，文字无挤占，虚线与卡边关系正确，字号未为塞文案变小 | 先减少次要信息，再重做；勿压扁字形 |
| 字体 | 主句保留毛体笔势，姓名流畅，数字衬线精致，正文较厚实清楚；无瘦长变形 | 修正提示，保留参考字面 |
| 材质 | 黑金纸面、左右明暗、接触阴影、圆角边缘和景深清楚；logo无脏污破碎，皮肤自然 | 母版重做，不反复锐化劣图 |
| 手机可读性 | 核心信息在相同显示宽度至少不逊于认可母版；对比够、无细瘦淡字 | 身份精简优先；仍不合格不得交成品 |
| 文件 | 原生比例/尺寸真实记录，未覆盖原图，实际回读，海报无制作标注 | 修复保存后再验证 |

## 最小QA记录

每条写 `pass / fail / not_applicable`、实际观察、引用的文件。`not_applicable` 要有具体理由（例如未给地域，并已目视清空）。另记 `fixed_region_drift`（none-visible / minor / material）、`avatar_fidelity`、`actual_dimensions`、`attempts`、`reviewer` 和 `status`。

同母版对照比较是视觉判断，不能把“无明显差异”写成“逐像素完全一致”。生成工具若没有蒙版参数，不能声称使用了蒙版锁定。

## 返修收敛

每件最多3次生成，都引用原始母版和原始头像；每次记录明确失败点。不要同时重做背景、logo、卡片和字体。三次仍有错字或头像变形时保留候选与失败原因，报告尚未通过；换确定性排版/图层替换方案需用户明确选择，不能在后台偷换生产路线。

## 发布包检查

公开逻辑包只能有流程、模板、脚本、说明。不得包含私有profile、带成员资料的母版、头像、实际任务记录、绝对机器路径、凭据或第三方对标图。检查压缩包实际文件及图像内容；文本扫描不等于隐私通过。公开包不宣称已有作者私有母版。
