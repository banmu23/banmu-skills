# AI同行者欢迎海报 · V2

依据授权资料与原始母版，按成员信息和空间适配正文，制作精致欢迎海报并实际查看原图与手机预览。

成员资料会随右栏空间调整信息量：主身份、相关经历优先，原文有内容时可补成长方向和同行期待；资料多时提炼，资料少时自然留白。保留曾任、希望等状态，不新增资历或成绩。头像与条码固定，正文分组和间距允许适配，不缩字硬塞。

每次从原始授权母版制作，保留品牌、材质与固定设计。生成后逐字核对姓名、编号、头像与固定文案，并真实查看原生图及手机尺度预览。生成式编辑不保证逐像素一致或每次零错字。

公开逻辑包不含客户资料、头像、私有品牌原图或内部母版。使用者配置自己的授权素材；需现场核验图像读取、编辑和保存能力。当前实测为Codex，不声称全部平台均已验证。
