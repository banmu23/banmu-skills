# AI同行者欢迎海报 · V1

依据授权资料与品牌配置制作多栏欢迎海报，包含清晰层级、准确文字、实际预览验收和版本保留。

公开逻辑包提供流程、通用模板与验收方法。使用前提供自己的品牌配置、客户授权资料、头像与可使用的参考素材；公开包不包含私人照片、客户资料、私有品牌原图或内部母版。

## 使用与交付

- 核对资料来源、姓名、编号与品牌文案，再精简上图信息。
- 以清晰层级、多栏信息和适当留白设计卡片，生成后逐字和目视复核。
- 使用实际手机预览尺寸检查阅读负担；定向修改已认可部分，并保留历史版本。
- 需要可用的生图能力与文件访问能力；各平台能力须现场核验，安装不等于全部平台已实测。
