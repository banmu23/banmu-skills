# 视觉 IP 配图引导

本文件用于生成和插入专属视觉 IP或客户自己的视觉 IP 正文插图。

## 1. 调用时机

严格顺序：

1. 先写文案。
2. 等用户确认文案。
3. 调用飞书美化能力美化文档。
4. 再调用视觉 IP 配图能力。
5. 插图后检查尺寸、比例、语义位置。

不要在文案未确认前提前生成插图，避免返工。

视觉 IP 配图不是可选项。文案确认、飞书美化和源图插入后，必须主动进入配图流程。

## 2. 如果已有专属视觉 IP Skill

内部默认调用 `customer-visual-ip-illustrations`。

画面标准：

- 16:9 PNG
- 纯白背景
- 手绘正文插图
- 专属视觉 IP形象稳定
- 表情阳光、可爱、有趣、变化丰富
- 不苦、不丧、不疲惫
- 少量红橙蓝中文手写批注
- 画面服务正文理解，不做无意义装饰

## 3. 如果客户没有小黑 Skill

先引导客户选择：

1. 使用客户自己的视觉 IP：让客户提供人物形象、品牌角色、参考图、口吻和禁忌。
2. 先搭一个客户视觉 IP Skill：把形象、风格、表情、场景、尺寸、禁用项写入 Skill。
3. 暂时使用通用解释型插图：不伪装成客户本人或真实证据。

没有客户确认，不要把专属视觉 IP直接当成客户视觉 IP。

如果客户没有视觉 IP Skill，不要说“没有就不配图”。要一步步引导客户完成：

```text
1. 明确客户的品牌人物 / 角色是谁
2. 收集 1-5 张参考图或形象描述
3. 写出表情、动作、服装、颜色、禁用风格
4. 设定输出尺寸：默认 16:9 PNG
5. 写成客户自己的视觉 IP Skill
6. 让客户安装 / 上传 / 授权
7. 再回到飞书知识库正文配图
```

## 4. 配图数量判断

按内容密度决定，不固定张数。

适合配图的位置：

- 核心判断
- 步骤开始处
- 新手最容易卡住的位置
- 工具选择节点
- 输入输出闭环
- 复盘和沉淀节点

不适合配图的位置：

- 每个小标题后机械插图
- 只是为了装饰
- 文本已经很短且没有理解难点
- 会误导成真实截图或真实案例证据的位置

## 5. 飞书插入审计

插入后检查：

```text
是否 PNG
是否 16:9
是否出现 512x512 正方形
是否有底部大白边
是否被压扁或拉伸
是否和上下文语义匹配
是否有错误文字
是否有不该出现的联系方式、二维码、平台诱导词
```

发现“白色下巴”或比例错误，重新生成或重新设置宽高，不要凑合交付。
