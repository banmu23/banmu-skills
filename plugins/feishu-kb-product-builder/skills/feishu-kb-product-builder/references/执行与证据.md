# V3 执行与证据协议

## 开始与接续

先读取流程图并确认本期方案、范围和任务目录。Agent 用 init_run.py 创建 run.json，禁止覆盖已有记录。模板中的 false、示例路径、哈希和客户信息必须替换为实际值，不能为了通过检查伪造证据。

```text
python3 scripts/init_run.py --directory 已确认任务目录
python3 scripts/resolve_visual_skill.py --run 已确认任务目录/run.json
python3 scripts/workflow_guard.py audit --run 已确认任务目录/run.json
```

任务记录默认私密，不进入公开安装包。证据文件使用任务目录内的相对路径，不能越出目录；来源原件不改动，在任务中保留获准的快照与原始位置记录。运行环境配置仅在视觉 Skill 路径处使用实际绝对路径，不复制到客户可见正文。

每个关卡用 workflow_guard.py gate 执行；所有前置通过才继续。下一篇 copy 需要前一篇 page 通过，不能批量写稿后补装证据。执行清单先首页，再模块和该模块正文；不能先子页后父页。

## 图片与充分性记录

originals.images 每张包含 id、usable。usable=false 必须说明原因；usable=true 必须有实际 path、sha256、anchor 和 inserted/included=true。source_total=0 也必须有核对来源确实无图的证据。

visual.images 每张包含 id、path、sha256、visual_pass、review_evidence、delivery_evidence、inserted/included。生成图必须有完整 PNG 块与校验，16:9；脚本只能检查文件结构/比例，不能验证它由 AI 生成、人物是否正确或中文是否清晰，后者必须实际打开检查并保存真实记录。

visual.coverage 每项包含 anchor、route（original/generated/text）、image_ids、required；文字足够时给 reason。每个 comprehension_points 中的理解点必须在 coverage 中出现；required_visual=true 时不能用 text 应付。每张生成图必须对应至少一个正文理解点。数字合规不代表配图充分，要另作 coverage_review_passed 与实际逐节复核证据；漏了重要步骤、转折、误区或闭环就继续补图。

只有 home/module 且 navigation_only=true、无重要理解点、确有 not_applicable_reason 的纯导航页可以零生成图，仍保存 coverage_evidence。正文不得走这条分支。

## 最新自有视觉 Skill

客户 plan.audience=customer、owner_id 与 visual_family 由实际资料/客户确认。visual_candidates 每个包含实际 path、owner_id、family、approved。Agent 只扫描客户允许的相关安装根目录/交付目录，列出已生成的自有同家族版本；新版本产生后更新清单，不能为沿用旧版故意漏列。解析器读取真实 SKILL.md 和 VERSION/metadata.version，同家族选择最高数字版本，兼容旧数字版本。同版内容不同或多家族未明确时停在必要选择，不能用文件修改时间猜。

内部 profile 默认指定内部自有家族，解析器会在本机 Codex 与 .agents 安装目录发现同家族候选。客户安装包 profile 不含服务方内部角色或路径，不能把通用基础 Skill 标成客户已魔改版本。无候选时按视觉IP配图引导推进至真实试图通过，再补归属确认与候选。

解析结果的 name/path/owner_id/family/version/skill_sha256/package_sha256 复制到 visual.skill，再加入 actual_call_verified、call_evidence、owner_evidence。任何 Skill 文件变化都会使原配图检查失效，需判断并复核。路径和归属声明仍须人或 Agent 实际核对，脚本不能证明所有权或替代真实调用。

## 完成与限制

state.json 保存关卡、依赖、产物及证据摘要。接续运行 audit；发现任何已确认产物或证据变动，重走受影响关卡。记录不是防篡改签名，也不能阻止 Agent 捏造内容，必须坚持真实读取、调用、目视和平台验证。

手动 content-package 完成仅指完整材料包；不得声称已上传/上线。目标为 feishu-live 时，即便采用手动上传，也必须收到真实回读与实际预览后才完成。

回归测试脚本只用隔离临时测试材料，不能拿测试通过冒充真实飞书、真实生图或跨平台实测。无 Python 环境人工按同一字段检查，明确未运行脚本。

V3增强：visual.images每张新增anchor/purpose/placement/scene/expression/lighting/edit_mode/preserve/qa_checks/qa_evidence，visual.group_review保存coverage/scene_expression/quality/passed/evidence。visual_contract.py与关卡检查真实字段和证据文件，不能证明目视本身。qa新增preservation_passed、presentation_clean、placement_review_passed与scope（预览方式/范围/未实测项）。V2旧记录先保留，迁移另存并重新核对，不自动继承旧关卡。
