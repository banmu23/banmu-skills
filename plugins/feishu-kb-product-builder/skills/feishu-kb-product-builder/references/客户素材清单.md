# 最小必要素材与变量

先从已有资料确认，只问真正缺失的关键项：产品主题与读者、指定资料源及禁止读取范围、目标飞书位置、新建/更新边界、作者署名、口吻、隐私边界、本期必需页面，以及客户自己的视觉小黑 Skill 或参考资料。

Agent 先扫描、分类和提炼，客户只纠错、补事实与确认方案。不要把一堆手填表或无关技术配置丢给新手。

区分来源全文、目录规划、真实图片、外链未读、客户反馈、价格权益与旧版本。缺关键正文时保留缺口，不编造。价格权益等动态口径使用最新证据；对外承诺变化需客户确认。

客户输出和安装包只含客户有权使用的资料与通用能力；不含他人专属角色、未授权截图、密钥、服务方私密路径或案例。
