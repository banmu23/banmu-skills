# 客户素材清单

当用户没有给全素材时，用这份清单做最小必要信息收集。不要一次问太多，优先问会影响执行的关键项。

## 1. 必要信息

```text
1. 这套知识库的产品标题或主题是什么？
2. 它卖给谁 / 给谁用？
3. 必须参考哪些素材？请提供文件夹、飞书链接、文档、图片、音视频或逐字稿。
4. 哪些内容不能参考？
5. 目标飞书知识库在哪里？如果没有打通飞书，先走手动草稿模式。
6. 作者署名怎么写？
7. 是否需要客户自己的视觉 IP 插图？
8. 是否要上架微信小店、小红书店铺或其他平台？
```

## 2. 可选信息

```text
品牌口吻：
禁用词：
价格/权益/承诺边界：
已有课程目录：
已有产品海报：
已有客户案例：
是否需要先做海报：
是否每次只写一个文档：
```

## 3. 素材边界确认模板

```text
我先按以下边界执行：

资料源：
- ...

不参考：
- ...

输出顺序：
1. 先确认标题和 2-3 级目录
2. 再搭飞书结构
3. 每次写一个文档
4. 文案确认后再美化
5. 美化后再插入源图和视觉 IP 图

你确认后，我再开始写入或生成。
```

## 4. 客户通用脱敏

客户可见包不得出现：

- 内部本地路径
- 内部客户名
- 他人专属产品名，除非用户已明确授权使用该名称
- 未授权聊天截图信息
- 未确认成交、收入、价格、名额、权益
- 任何让客户误以为结果被保证的表达

替换为：

```text
你的核心产品
你的高价值项目
你的代表案例
你的课程资料
你的客户问题
你的知识库
你的视觉 IP
```
