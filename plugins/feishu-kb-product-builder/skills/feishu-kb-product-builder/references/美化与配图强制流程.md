# 美化与配图强制流程

本文件是飞书知识库产品每篇文档的后半段执行门槛。只要进入真实交付，就不能跳过。

## 1. 固定顺序

每篇首页、模块文档、小节正文文档都必须按顺序执行：

```text
1. 文案完成
2. 用户确认文案
3. 主动调用飞书美化 Skill / 能力
4. 如果没有飞书美化 Skill，就手动把飞书文档美化到当前环境最优解
5. 插入本篇用得上的原课件图 / 源飞书图 / 真实素材图
6. 主动调用专属视觉 IP或客户自己的视觉 IP 配图 Skill
7. 如果客户没有视觉 IP 配图 Skill，就一步步引导客户安装、创建或改造
8. 插入生成图
9. 检查图片比例、白边、压缩、位置、说明和文档整体效果
```

不能跳过第 3 步和第 6 步。不能把它们写成“可选”。

## 2. 飞书美化 Skill 调用规则

如果当前环境存在 `feishu-doc-beautifier`、飞书美化文档 Skill、飞书文档美化能力或等价工具，必须主动调用。

调用目标：

- 首页：做成产品入口页，有清楚开篇、表格、全局导航、使用路径。
- 模块文档：做成提纲挈领的模块索引页，有子页面导航和小节提炼表。
- 小节正文：做成可跟做教程，有步骤、口令、检查清单、验收标准。

如果没有安装或无法调用：

- 明确告诉用户当前缺少飞书美化 Skill / 能力。
- 不要停止任务。
- 用当前能用的飞书编辑能力或可复制排版稿做到最优：
  - 信息栏 / callout
  - 表格
  - 检查清单
  - 分隔线
  - 子页面导航
  - 清晰标题层级
  - 口令代码块
  - 验收标准块
- 如果客户愿意安装，再一步步引导客户安装或授权。

## 3. 视觉 IP 配图 Skill 调用规则

### 内部

如果是内部知识库，必须主动调用：

```text
customer-visual-ip-illustrations
```

要求：

- 先美化文档，再生成专属视觉 IP图。
- 图要服务正文理解，不做装饰。
- 数量按内容密度，不固定两张。
- 插入后检查比例，避免白色下巴、512x512、压缩变形。

### 客户使用

客户使用这个 Skill 时，不叫“专属视觉 IP”。它应该叫客户自己的：

```text
视觉 IP 配图 Skill
客户小黑 Skill
客户品牌角色插图 Skill
```

执行顺序：

1. 询问客户是否已有自己的视觉 IP / 小黑 Skill。
2. 如果已安装，确认 Skill 名称和形象规则，文档美化后主动调用。
3. 如果没有安装，引导客户准备：
   - 人物或品牌角色定位
   - 参考图
   - 表情规则
   - 画风规则
   - 禁用风格
   - 图片尺寸
   - 输出格式
   - 插图使用场景
4. 帮客户把这些规则整理成可安装 / 可上传 / 可复制的视觉 IP Skill。
5. 客户确认后，再用该视觉 IP Skill 给知识库配图。

不要未经授权把专属视觉 IP当成客户的默认形象。

## 4. 检查清单

完成每篇文档后检查：

```text
文案是否已确认
是否已经调用飞书美化 Skill
如果没调用，是否说明原因并做了手动最优美化
是否插入了所有可用源图
是否调用了专属视觉 IP / 客户视觉 IP Skill
如果客户没有视觉 IP Skill，是否给了安装和改造步骤
图片数量是否按内容适配
图片是否有白色下巴
图片是否被压缩、拉伸或变形
模块页是否仍然精炼
小节正文是否足够实操
```

没有通过检查，不要说文档已经完成。
