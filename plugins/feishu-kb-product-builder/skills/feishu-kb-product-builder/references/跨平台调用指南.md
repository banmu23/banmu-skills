# 跨平台调用与能力边界

复制给当前 Agent：

```text
请使用 $feishu-kb-product-builder，按 V3 确定流程把我提供的真实素材做成飞书知识库。
先读允许的来源，确认主题、人群、素材边界、首页/二级模块/三级正文、目标位置和执行范围。
确认后默认逐篇：文案确认 → 美化 → 所有可用原图 → 充分的最新自有视觉小黑配图 → 单篇验收。
我没有自己的视觉小黑 Skill 时，请分小步带我安装基础能力并魔改成自己的版本，实际试图通过后再继续。
按流程节点保存选择与证据，执行阶段门槛；缺能力或未通过时不要假称完成。
```

核心流程相同，实际能力按当前 Codex、Claude Code、ChatGPT、Hermes、Workbuddy、ima copilot 等环境验证，不因指南列出平台就声称实测兼容。

有本地文件与 Python：运行阶段检查和视觉依赖解析。没有 Python：Agent 按同一 run-template 字段逐项核对并保存人工结果，明确本轮未跑脚本，不得伪称通过。无飞书连接：按已确认手动内容目标交付，保留上传与在线验收缺口。无生图能力：保存计划/提示词与断点，继续引导打通，不能用程序图或他人角色充数。
