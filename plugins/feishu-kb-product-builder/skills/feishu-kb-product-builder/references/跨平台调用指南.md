# 跨平台调用指南

本 Skill 需要兼容 Codex、Claude Code、ChatGPT、Hermes、Workbuddy、ima copilot 等主流 Agent。不同平台能力不同，核心流程不变。

## 1. 通用调用提示词

```text
请使用 $feishu-kb-product-builder，基于我提供的素材，帮我制作一套可售卖/可交付的飞书知识库产品。

要求：
1. 先和我互动确认产品标题、素材边界、目录结构、页面层级、执行顺序。
2. 我确认方案后，再执行具体写入、生成、配图或搭建动作。
3. 只围绕我提供的素材写，不编造案例、收益、价格、结果。
4. 首页、模块页、正文页分开写；模块页精炼，正文页详细实操。
5. 文案确认后必须主动调用飞书美化能力；如果没有安装，就手动美化到当前环境最优。
6. 飞书美化后必须主动调用专属视觉 IP / 客户视觉 IP 配图能力；客户没有安装就引导安装或改造。
7. 如果你无法直接操作飞书，请输出可复制到飞书的文档草稿、美化方案、图片插入说明和视觉 IP 配图安装/调用步骤。
```

## 2. Codex / Claude Code

适合：

- 读取本地素材目录
- 处理 Markdown / 图片 / 文档
- 调用飞书 CLI 或连接器
- 生成 Skill 包和交付包
- 批量检查图片尺寸和结构

执行时仍要先给方案，等确认后再写入。

## 3. ChatGPT

适合：

- 目录方案
- 单篇文档撰写
- 文案润色
- 手动复制版飞书文档
- 配图提示词

如果不能连接飞书，让 ChatGPT 先输出文档草稿、飞书手动美化方案、图片位说明，以及视觉 IP 配图提示词 / 安装引导。

## 4. Workbuddy / ima copilot

适合：

- 基于上传资料做问答、归纳、写草稿
- 帮用户梳理知识库结构
- 做轻量 Agent 工作流

如果平台无法直接写入飞书：

1. 先生成结构和每篇正文。
2. 主动给出飞书美化方案，不跳过排版。
3. 主动进入客户视觉 IP 配图流程；如果客户没有 Skill，就引导创建或安装。
4. 让用户复制到飞书。
5. 再根据飞书截图或链接迭代。

## 5. Hermes

适合：

- 收集微信、群聊、临时素材
- 提炼素材入口
- 生成待入库草稿

Hermes 不应直接大规模改知识库结构，除非用户已授权并确认方案。

## 6. 无飞书连接时的交付方式

仍然可以交付：

- 知识库目录树
- 首页 Markdown
- 模块页 Markdown
- 正文 Markdown
- 飞书美化方案
- 图片插入位置说明
- 配图需求清单
- 视觉 IP Skill 安装 / 改造步骤
- 手动上传检查清单

等飞书打通后，再迁移进去。
